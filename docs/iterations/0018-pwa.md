# Iteration 18 — PWA (installable + offline)

**Date:** 2026-05-14.
**Status:** Complete.

## Goal

Make the game installable as a PWA and fully playable offline per SPEC §1 and §12 AC10. Generates a web app manifest, registers a service worker that precaches every static asset (including the seven MP3s), and ships home-screen-ready PNG icons.

Tooling: **vite-plugin-pwa** wraps Workbox, generates the manifest, and auto-registers the service worker. Icon PNGs are generated from an SVG source by a one-shot Playwright-based script committed under `scripts/`.

## Acceptance criteria

1. **Plugin wired:** `vite-plugin-pwa` is installed as a devDependency and configured in `vite.config.ts` with:
   - `registerType: 'autoUpdate'` (new versions activate on next page load).
   - `injectRegister: 'auto'` (registration code injected at build time; `src/main.ts` stays clean).
   - Manifest fields: `name = "Blockly"`, `short_name = "Blockly"`, `description`, `theme_color = "#0F172A"`, `background_color = "#0F172A"`, `display = "standalone"`, `start_url = "/"`, `scope = "/"`, `orientation = "any"`, `lang = "en"`.
   - Manifest `icons`: `/icons/icon-192.png` (192×192, `purpose: "any maskable"`), `/icons/icon-512.png` (512×512, `purpose: "any maskable"`).
   - Workbox `globPatterns: ['**/*.{js,css,html,mp3,png,svg,ico,webmanifest}']` so the seven SFX and the icons are precached for offline play.

2. **Icon source:** `public/icons/icon.svg` defines the brand mark — a deep-slate `#0F172A` rounded square with a 2 × 2 arrangement of piece-coloured tiles (sky / orange / violet / green). Centred content stays within the 80% safe zone so the icon survives maskable rendering on Android.

3. **Generated PNG icons:**
   - `public/icons/icon-192.png`
   - `public/icons/icon-512.png`
   - `public/icons/apple-touch-icon.png` (180×180, iOS home-screen)

4. **Icon-generation script:** `scripts/generate-icons.mjs` uses Playwright's Chromium to render `icon.svg` at the three target sizes and write PNGs to `public/icons/`. The script is one-shot (run manually when the SVG changes) and idempotent.

5. **`index.html` updates:**
   - `<link rel="apple-touch-icon" href="/icons/apple-touch-icon.png">` so iOS home-screen install picks up the proper icon.
   - Existing `theme-color`, `apple-mobile-web-app-capable`, viewport meta tags stay.

6. **`package.json`** gains a `generate:icons` script that runs the icon-generator.

7. **Build output**: running `npm run build` produces a `dist/manifest.webmanifest` and a `dist/sw.js` (or equivalent service worker file) alongside the existing JS/CSS bundles.

## Out of scope

- A custom in-page "Install" prompt or `beforeinstallprompt` handling.
- A "New version available — reload?" banner.
- Push notifications.
- Background sync.
